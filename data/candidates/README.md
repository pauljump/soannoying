# Screened candidates

These are the result of a corpus-level Big Annoyance Test pass over the private source-tracked corpus. The current dated file contains 54 finalists from 4,932 raw annoyances and 5,578 archived sources.

They are **screened candidates**, not reviewed problem records. The source links show why each pattern is worth a closer look. The wording is a working description, not a claim that the problem is common or solved.

The compiler merged overlapping rows and kept patterns that looked repeated, costly, hard to work around, and broader than one isolated product complaint. It used Codex `gpt-5.5` at low reasoning effort. A source audit confirmed that every retained candidate resolves to real corpus evidence and an archived URL. Fifty-two have multiple distinct source URLs; two rely on one unusually strong source. The candidates are still not reviewed problem records.

The next step is community review: merge overlapping candidates, reject weak ones, add better evidence, and only then create records in `data/problems/`.
