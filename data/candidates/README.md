# Screened candidates

These are the result of a corpus-level Big Annoyance Test pass over the private source-tracked corpus. The current dated file contains 50 finalists from 5,761 raw annoyances and 6,421 archived sources.

These are the screened source records behind the current public final set. They are not reviewed problem records. The source links show why each pattern made the release boundary. The wording is a working description, not a claim that the problem is common or solved.

The compiler merged overlapping rows and kept patterns that looked repeated, costly, hard to work around, and broader than one isolated product complaint. It used Codex `gpt-5.5` at low reasoning effort. A source audit confirmed that every retained candidate resolves to real corpus evidence and an archived URL, with multiple distinct source URLs for every candidate. The candidates are still not reviewed problem records.

The next step is deeper review when a record is going to become a formal problem record: merge overlapping candidates, reject weak ones, add better evidence, and only then create records in `data/problems/`. The public page can publish an annoyance before that later solution and validation work is complete.
